O que as imagens mostram

Versão radicalizada do Coquette, no espírito dos Corvette Z06: bitolas mais largas, aerodinâmica agressiva, motor mais bravo. O Z06 é tradicionalmente a versão que a Chevrolet prepara para as pistas sem deixar de homologá-la para as ruas. O primeiro trailer o faz surgir numa cena noturna.

O equivalente real

A comparação escolhida para este veículo é com o Chevrolet Corvette C8. Encare como o que é: uma leitura das imagens divulgadas. A Rockstar nunca comentou os modelos que usa como ponto de partida.
