Sources, par ordre de confiance :
- Rockstar : site officiel, Newswire, manuel du jeu, textes en jeu → statut official (« officiel » dans prix_gta6) ;
- relevés faits en jeu par moi (je te les donnerai si tu me les demandes) → statut verified ;
- guides de médias reconnus (IGN, GameSpot, Polygon, jeuxvideo.com, Millenium, Gameblog, JeuxActu…) → au moins deux sources concordantes pour un chiffre : statut media, avec la première adresse dans source et l'autre (ou les autres) dans sources ; une seule source : statut estimated ;
- wikis communautaires (GTA Wiki…) → statut community (ou comm), jamais official.
Chaque valeur chiffrée prend la forme {value, status, source, verifiedAt, unit} (dans les listes : prix_gta6 { valeur, statut, source, verifiedAt }), avec une adresse https déclarée dans le fichier de sources de la donnée (outils/missions/hub.json et outils/activites/hub.json → sources, outils/acquisitions.json → sources, outils/catalogues/sources.json ; statut de la source : officiel, vu pour un média, comm pour la communauté) et la date de consultation dans verifiedAt (AAAA-MM-JJ). Les statuts official, verified, media et community exigent source et verifiedAt ; un chiffre mal formé arrête la génération en disant pourquoi. Les anciens statuts vu et observed (repéré dans une vidéo officielle) ne servent pas pour un chiffre de média. Une valeur inconnue s'écrit { value: null, status: "unknown" } (dans les listes : valeur null, statut "conf").
