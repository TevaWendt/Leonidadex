The essentials

The game and the Ultimate upgrade: sixteen extra items, spread across Jason and Lucia’s story, discovered chapter by chapter. What it includes: the full game, digital; sixteen extra items, discovered as the story goes on; the same pre-order bonuses. Recorded price: 99,99 € on the PlayStation Store; each retailer sets its own. The sixteen extra contents each have their page, listed below. With the Standard Edition, the Ultimate upgrade is sold separately, digitally, on the PlayStation Store or the Microsoft Store, at any time once the game code is redeemed. Boxed: The box contains a download code, not a disc. It’s available from November 12, 2026, for delivery or pickup at the retailer, and its code lets you preload the game from that day. There’s no boxed Ultimate Edition: with the boxed version, you buy the Ultimate upgrade digitally once the code is redeemed.
