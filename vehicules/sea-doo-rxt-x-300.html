L’essentiel

Jet-ski trois places à forte puissance, distinct du Seashark qui figure déjà dans cette base. Le RXT-X est la version sportive de la gamme, celle qui dépasse les cent kilomètres-heure. Nom en jeu non communiqué.

Le modèle qui l’inspire

Le rapprochement retenu pour ce véhicule est Sea-Doo RXT-X 300. Le studio garde le silence sur ses références. Ce rapprochement repose sur la comparaison des images officielles, rien de plus.
