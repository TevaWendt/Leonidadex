Ce qu'il faut savoir

Le Marquis apparaît dans les supports officiels sans nom communiqué. C'est un voilier de croisière habitable, dans l'esprit du Bavaria Cruiser 46 : mât unique, cockpit arrière, cabines sous le pont. Le type de bateau qu'on trouve amarré dans les marinas recensées sur notre carte.

Le modèle réel

Le rapprochement retenu pour ce véhicule est Adjutor Yachts. Rockstar ne confirme jamais ses inspirations : c'est une observation établie à partir des visuels officiels, pas une licence.
