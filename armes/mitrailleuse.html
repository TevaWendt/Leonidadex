En clair

Catégorie mitrailleuses : voilà où Mitrailleuse de combat se range dans notre base. Aperçue dans les visuels officiels, sans étiquette : la fiche la désigne par son type et par son modèle réel probable. C’est une arme longue : dans le jeu, elle se porte dans le dos ou en main, et le nombre d’armes longues qu’on peut emporter est limité. Sa silhouette rappelle M249 SAW : c’est l’inspiration réelle retenue, sans confirmation de Rockstar. Elle utilise des munitions lourdes. Sa portée estimée est moyenne.

Ce qui manque encore (dégâts, portée effective, prix, accessoires) viendra de relevés en jeu, jamais d’estimations.

Le rôle de cette catégorie

Dans un GTA, une mitrailleuse est faite pour les situations où le nombre d’ennemis dépasse les munitions d’un fusil.
