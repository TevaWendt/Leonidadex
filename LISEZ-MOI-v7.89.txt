CE QUI CHANGE POUR LE VISITEUR
- Leonidakit s'installe comme une appli, sur téléphone, tablette et ordinateur : le soleil du site sur l'écran
  d'accueil, plein écran sans barre du navigateur, raccourcis Carte, Calculateur, Progression et Mode compagnon, dans la
  langue de la page.
- Sans réseau, le site marche pour ce qui a déjà été vu : les pages déjà ouvertes s'affichent ; une page jamais vue
  donne « Pas de réseau pour l'instant » (dans la langue), avec la liste des pages gardées sur l'appareil. Avec du réseau,
  rien ne change : on a toujours la dernière version.
- Nouvelle page Mode compagnon (compagnon.html, cinq langues ; menu Explorer › Le site, pied de page Outils et aide) :
  la carte, les carnets, le calculateur et Léo en grandes tuiles ; « Préparer pour jouer sans réseau » (accueil, carte,
  calculateur, progression, les 9 carnets et Léo, environ 7 Mo) ; « Installer l'appli » (en un geste quand le navigateur
  le propose, sinon la marche à suivre pour iPhone, Android ou ordinateur) ; « Garder l'écran allumé » pendant la partie ;
  questions fréquentes.
- Changer d'appareil, sans compte ni serveur (Mode compagnon et page Progression) : « Créer le lien de transfert » donne
  un lien et un QR code avec tout le suivi (cases cochées, calculs, plans) ; sur l'autre appareil, un aperçu puis
  Fusionner, Remplacer ou Annuler. Le fichier (exporter / importer) reste proposé.
- Mentions : ce que garde le service worker et comment l'effacer, l'écran allumé, le transfert ; toujours aucun cookie.
- Léo répond à « comment installer le site ? », « ça marche sans réseau ? », « comment passer ma progression sur un
  autre téléphone ? ». Tuto : « Comment emporter mes données sur un autre appareil ? » commence par le lien de transfert.

MARCHE À SUIVRE (après l'assemblage)
  1. La conversation d'assemblage copie l'archive avec les autres, régénère (outils/regenerer.cjs : gen-compagnon.cjs y
     est déjà, avant gen-informations.cjs) et lance les contrôles. Le numéro de version du service worker (sw.js) est
     réécrit tout seul par la régénération : rien à faire à la main.
  2. Toi : copie le résultat de l'assemblage à la racine du dossier GitHub (remplacer), valide, pousse.
  3. Google Search Console → Sitemaps : renvoie sitemap.xml ; Inspection de l'URL → « Demander une indexation » pour
     compagnon.html.
  4. Essai sur ton téléphone, en https (le service worker ne marche qu'en https) :
     - ouvre compagnon.html, touche « Préparer pour jouer sans réseau », attends « Prêt à jouer sans réseau » ;
     - passe en mode avion : ouvre la carte, un carnet, le calculateur, Léo ; puis une page jamais ouverte → « Pas de
       réseau pour l'instant » ;
     - « Installer l'appli » (Android : le bouton ; iPhone : Partager → Sur l'écran d'accueil) ;
     - sur un ordinateur, « Créer le lien de transfert », scanne le QR code avec le téléphone → aperçu → Fusionner.
