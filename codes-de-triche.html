Chaque information dit d’où elle vient : page de Rockstar, presse ou guide de joueurs. Aucun code supposé, aucune liste tirée des fuites : un code de GTA VI n’entrera ici que publié par Rockstar ou vérifié en jeu. Comprendre les statuts.

Comment marchaient les codes dans GTA V

Des codes de GTA V, montrés pour comparer : ils ne marchent pas dans GTA VI. Trois façons de les entrer, et des règles écrites par Rockstar.

À la manette

En pleine partie, on tapait une suite de touches : croix directionnelle, boutons et gâchettes.

Au téléphone du jeu

On composait un numéro en 1-999 : les chiffres suivants épellent le nom du code sur le clavier du téléphone. Sur PS3 et Xbox 360, seules les touches marchaient.

Sur PC, dans la console

05

Questions

Questions fréquentes

Les questions qu’on tape dans un moteur de recherche, avec des réponses courtes et datées.

Y a-t-il des codes de triche dans GTA 6 ?
Rien n’est annoncé au 4 octobre 2026 : ni Rockstar ni Take-Two n’ont parlé de codes de triche pour GTA VI, et ni l’Extended Look ni le dossier de Game Informer n’en montrent. Les listes « GTA 6 » qui circulent sont des spéculations ou viennent des fuites : le site n’en reprend aucune. Depuis GTA III, chaque grand GTA en a eu ; dans GTA V, on les tapait à la manette, au téléphone du jeu ou, sur PC, dans la console.
Existe-t-il un code d’argent infini dans GTA 6 ?
Non. Aucun code n’est annoncé pour GTA VI, et donc aucun code d’argent. Dans GTA V, aucun code ne donnait d’argent, d’après les guides de joueurs ; dans San Andreas, HESOYAM donnait 250 000 $ avec la santé et l’armure. Pour préparer tes achats, le calculateur part de tes propres chiffres.
Les codes de triche désactivent-ils les trophées ?
Dans GTA V, oui, pour un temps : Rockstar précise qu’on peut sauvegarder avec un code actif, mais que les succès sont désactivés ; recharger une sauvegarde ou redémarrer la console annule tous les codes. Pour GTA VI, rien n’est publié : ni codes, ni règle sur les trophées et les succès.
Comment entrer un code de triche avec le téléphone ?
Dans GTA V, on ouvrait le téléphone du jeu et on composait un numéro en 1-999 : les chiffres suivants épellent le nom du code, comme 1-999-866-587 pour TOOLUP, les armes. Sur PC, la console s’ouvre avec la touche ² d’un clavier français, ou ~. Pour GTA VI, la façon d’entrer d’éventuels codes n’est pas connue.
Les codes de triche marchent-ils en ligne ?
Dans GTA V, non : d’après les joueurs, les codes ne servaient qu’en mode histoire, et GTA Online ne les acceptait pas. GTA VI sort d’abord comme une expérience solo, sans code annoncé.
