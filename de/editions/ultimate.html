Das Wichtigste

Das Spiel und das Ultimate-Upgrade: sechzehn zusätzliche Inhalte, verteilt über die Geschichte von Jason und Lucia, die man Kapitel für Kapitel entdeckt. Was sie umfasst: Das komplette Spiel, digital; Sechzehn zusätzliche Inhalte, die du im Lauf der Geschichte entdeckst; Dieselben Vorbestellerboni. Erfasster Preis: 99,99 € im PlayStation Store; jeder Händler legt seinen eigenen fest. Die sechzehn zusätzlichen Inhalte haben je ihre Seite, unten aufgeführt. Zur Standard Edition kauft man das Ultimate-Upgrade separat und digital im PlayStation Store oder im Microsoft Store, jederzeit, sobald der Code des Spiels eingelöst ist. Als Box: Die Box enthält einen Download-Code, keine Disc. Sie ist ab dem 12. November 2026 erhältlich, per Lieferung oder zur Abholung beim Händler, und mit ihrem Code kann man den Preload ab diesem Tag starten. Die Ultimate Edition gibt es nicht als Box-Version: Mit der Box kauft man das Ultimate-Upgrade digital, sobald der Code eingelöst ist.
